# Contributing to esp32-matter-CWWW-LED-controller

Thank you for your interest in improving this project! Contributions, bug reports, and hardware suggestions are always welcome.

## How to Contribute

1. **Report Issues**: If you experience an issue or have a feature request, please open a GitHub Issue with:
   - Your ESP32-C6 board variant.
   - Your smart home ecosystem (Apple Home, Google Home, Home Assistant, etc.).
   - Serial monitor logs (`idf.py monitor`).
2. **Pull Requests**:
   - Fork the repository and create a feature branch (`git checkout -b feature/awesome-feature`).
   - Follow the existing code style (see `.editorconfig`).
   - Commit your changes with clear, descriptive commit messages.
   - Push to your branch and open a Pull Request.
